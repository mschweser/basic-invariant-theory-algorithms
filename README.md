# basic invariant theory algorithms

This code is part of my bachelor thesis "Invariant theory of finite groups". It implements three basic algorithms in Julia using [Oscar](https://github.com/oscar-system/Oscar.jl): computing generators of an invariant ring, testing membership and finding representations, and computing relations between generators.

## Files

- `src/generators.jl`: computes generators of an invariant ring for a finite matrix group over a field of characteristic zero.
- `src/f_in_IR.jl`: tests whether a polynomial belongs to the algebra generated by given polynomials and expresses it in terms of them.
- `src/relations_ideal.jl`: computes a Gröbner basis of the ideal of relations between the given polynomials and returns both the ideal and its Gröbner basis.
- `src/generators_and_membership.jl`: combines generator computation and membership testing.
- `src/helpers.jl`: helper functions used by the generator algorithm.
- `src/generate_examples.jl`: generate examples for my thesis.
- `test/`: tests for the three main algorithms.

## Usage

Install Julia, then install Oscar in the Julia REPL:

```julia
using Pkg
Pkg.add("Oscar")
```

Start Julia from the repository's root directory. To run the examples:

```julia
include("src/generate_examples.jl")
```

To use the algorithms with your own input:

```julia
using Oscar
include("src/generators_and_membership.jl")
include("src/relations_ideal.jl")

R, (x, y) = graded_polynomial_ring(QQ, [:x, :y])
G = matrix_group(QQ, [-identity_matrix(QQ, 2)])

F = compute_generators(R, G; debug = false)
belongs, h = membership_representation(F, x^4 + x^2*y^2)
I_F, basis = relations_ideal(F, R)
```

Here, `F` generates the invariant ring, `belongs` indicates membership, and `h` expresses the input polynomial in terms of `F`. If membership fails, `h` is `nothing`. The outputs `I_F` and `basis` are the relation ideal and its Gröbner basis.

Run the tests from the repository's root directory:

```sh
julia test/test_generators.jl
julia test/test_f_in_IR.jl
julia test/test_relations_ideal.jl
```
